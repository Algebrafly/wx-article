阿里云百炼视频生成 Prompt 指南在 10 月 10 号和文生文、文生图两篇同一天更新。三篇是姊妹篇，按「文字 → 图像 → 视频」的顺序来。视频这篇最复杂——万相 2.6、2.7、3.0 三代模型公式不一样。

它的核心思路和文生图类似：先给基础公式，再给进阶扩展。但视频和图像有一个本质差别——图像只要描述静态内容，视频必须描述**运动**。万相 3.0+ 还多了声音。

01

视频 prompt 比图像 prompt 多了什么

文生图基础公式是「主体 + 场景 + 风格」。到了视频，第三条换成**运动**。万相文档里写得很直白：视频 prompt 的核心是「描述视频中所包含的画面内容和**运动过程**」。

运动这个词比风格难写。它可以是静止、小幅度摆动、大幅度奔跑、局部表情变化、或者一个完整的动作链（打碎玻璃、捡起钥匙、递给别人）。幅度、速率、作用效果都要写清楚。

更重要的是：视频不止一种输入。万相支持文生视频、图生视频（首帧或首尾帧）、参考生视频（上传参考视频/图片）。每种输入的公式都不一样。

三种输入模式，三种公式。参考生视频最灵活，能用 图n / 视频n 指代。

02

三条核心公式

先看三条最核心的公式，覆盖了最常见的两种输入。

基础打底，进阶往上盖，图生视频单独来一条。

基础公式：主体 + 场景 + 运动。和文生图对比，就是把「风格」换成了「运动」。这是视频 prompt 和图像 prompt 最本质的结构差别。「一只毛茸茸的小奶猫 + 下雪的院子 + 缓慢地摇尾巴」——够了，模型能出东西。

进阶公式在基础之上再盖两层：每一项都加描述（主体描述、场景描述、运动描述），然后再加上**美学控制**（光源、景别、视角、镜头、运镜）和**风格化**（赛博朋克、勾线插画、废土风格）。和文生图的进阶公式比，多了运镜，少了氛围词——视频本身就在制造情绪。

图生视频公式：运动 + 运镜。图已经定了主体、场景和风格，不需要再写一遍。prompt 只需要告诉模型：图里的东西怎么动（奔跑、打招呼），镜头动不动（固定镜头 / 推进 / 左移）。这是一个大幅简化的公式。

三条公式的关系和文生图那篇一样：基础打底，进阶往上盖，特殊输入有专用公式。

03

多镜头：万相 2.7 / 2.6 的大杀器

万相 2.7 和 2.6 能生成**多镜头连贯叙事视频**。这意味着你可以写一个有起承转合的短剧 prompt，模型会自动按镜头切。这比单镜头出一个 10 秒片段强太多。

多镜头公式的结构是：**总体描述 + 镜头序号 + 时间戳 + 分镜内容**。先给模型一个全局故事框架，再按镜头编号、时间戳、镜头内容一步步写。

总体描述加在最前面，每个镜头带时间戳，像写分镜脚本。

时间戳的写法是「镜头1[0-3秒]」「镜头2[4-6秒]」，模型会按时间戳分配镜头长度。总体描述要简要——第三人称视角、什么故事、什么情绪——让模型知道全局走向。

另外要注意：万相 2.7 不再支持用 shot_type 指定单/多镜头了，由模型自己判断。想一镜到底，中文写「生成单镜头」，英文写「Generate single shot.」。

04

声音：万相 3.0+ 的新能力

万相 3.0、2.7、2.6、2.5 有原生音频能力。声音公式就是在基础公式后面加一项：主体 + 场景 + 运动 + **声音描述**。声音描述分三类：人声、音效、BGM。

三类声音，描述维度不一样。

人声最复杂，六个维度：说话内容 + 情绪 + 语调 + 语速 + 音色 + 口音。比如「一个男人讲脱口秀，他说道："好好学习，天天向上"，语气轻松，语速适中，声音清亮，美式英文」——这是完整的人声描述。

音效三个维度：音源材质 + 行为 + 环境音。玻璃小球掉在木质地面发出"砰"的声音，室内安静环境——材质和环境一起写，音效会很准。

BGM最简单，背景音乐 + 风格。不写的话模型会根据题材自己发挥；不想有背景音乐，明确写「无背景音乐」。

05

优化技巧 + 示例

文生视频 prompt 也可以自动优化。API 调用时开 prompt_extend 参数（和文生文、文生图一样），简短宽泛的 prompt 效果提升最好。或者把公式喂给大语言模型（文档给的例子是 qwen3.6-plus），让它按公式帮你扩写。

一个按声音公式写的完整 prompt：

主体：一只毛茸茸的小奶猫 场景：下雪的院子 运动：缓慢地摇尾巴，突然跳起来抓雪花 声音描述： 人声：无 音效：软乎乎的爪垫踩雪的声音，雪花飘落的细碎声 BGM：温馨舒缓的钢琴旋律，轻雪风格

如果是图生视频，主体和场景已经在图里了，prompt 可以简化成：

运动：缓慢地摇尾巴，突然跳起来抓雪花 运镜：固定镜头 声音描述：音效 + 温馨钢琴 BGM（同上）

参考生视频还有一个约定：用「图1」「视频1」指代参考文件，中英文都写（「Image 1」「Video 1」）。只有一个参考时可以简化成「参考图片」。

视频 prompt = 图像 prompt + 运动 + （可选）声音。图像定风格，运动定生命，声音定氛围。
