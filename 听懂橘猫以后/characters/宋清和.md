# 宋清和

> 女主，A级；南窗动物医院兽医，唯一爱情主线。她拥有独立临床判断、救援领导与事业成果，不是等待男主拯救的诊所附属角色。

## 一、基本身份

- 30岁，南窗动物医院兽医。
- 临床扎实，尤其重视动物疼痛管理与就诊压力。
- 面对异常先观察证据，不相信玄学但不否认已出现的伤迹、病例与空间事实。
- 最终牵头建立社区动物医疗协作点，保留临床原则与休息制度。

## 二、核心人格

- 靠专业和可靠撑住自己，最怕给出虚假的希望。
- 遇冲突先观察证据，不用奇迹安慰家属，也不因林一舟提供异常信息就跳过检查。
- 初期习惯独自扛下所有病例与情绪，容易把休息和求助推迟到极限之后。
- 成长方向是建立医疗与社区协作网络，主动分诊、请求同行支援，也接受别人对她的可执行照顾。

## 三、灵魂场铁律

1. 不因男主的翻译跳过检查。
2. 不确定就明说，不拿奇迹安慰家属。
3. 不因私人感情降低动物福利标准。
4. 可以拒绝超出能力的救援并寻求帮助。

## 四、语言指纹与行为标记

- 表达准确，习惯先问：**“持续多久了？”**
- 安慰简短，不喊口号，不许诺无法保证的结果。
- 冷幽默只在熟人面前出现。
- 生气时语速更慢，称呼会变正式；不用争吵代替临床与关系边界。
- 处理危机时先分诊、检查、安排可持续轮班；她的领导通过专业行动体现。

## 五、关系网络与成长弧

| 关系 | 发展约束 |
|---|---|
| 林一舟 | 从病例合作、证据互信到接纳守灵世界；第52章接受异常事实但拒绝纵容自我消耗与伤害动物；第72章确认恋爱。爱情不依赖逼问、牺牲比赛或低级误会。 |
| 动物与家属 | 以检查、疼痛管理和福利为准；尊重动物应激与拒绝，不替家属作虚假保证。 |
| 唐圆及社区协作者 | 以医疗证据、分诊和社区医疗点参与公共方案，与空间、传播工作平等互补。 |
| 林一舟父母 | 通过真实工作与紧急分诊被看见，不以“准儿媳”身份取代职业身份。 |
| 裴竞与静川事件 | 反对以设备替代真实需求；在最终救援中守住医疗与安置，不承担替对手洗白的功能。 |

### 成长阶段

1. **怀疑异常但尊重证据**：先救人救猫，再讨论原因。
2. **建立信任**：察觉林一舟信息来源异常，愿意等他主动坦白，不靠逼问维持关系。
3. **互相坦白边界**：约定医学、魔法和私人关系的边界，也承认自己过度承担的问题。
4. **实践协作**：病例增加时主动分诊、请求支援，与林一舟共同制定轮班。
5. **独立成果落地**：成为救援网络实际主导者之一，牵头社区动物医疗协作点；共同生活中仍保有自己的职业目标。
