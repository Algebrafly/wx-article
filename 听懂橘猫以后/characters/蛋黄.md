# 蛋黄

> 橘猫，A级；林一舟的搭档而非宠物工具、导师百科或战斗能力来源。

## 一、基本身份

- 四岁公猫。
- 曾陪伴前守灵人何穗，后主动选择林一舟。
- 与林一舟共同生活八个月；雨夜救助触发承接，第25章说明其考察与选择。
- 爱吃，但不会因为食物无原则泄密。

## 二、核心人格

- 重视领地、承诺与可预期的生活。
- 看似傲慢，实则敏锐地保护新搭档。
- 会观察、拒绝、生气和离开，不承担随时解答世界规则的功能。
- 对林一舟的信任必须建立在兑现承诺、尊重拒绝和独立选择上，而非人类自称守灵人。

## 三、灵魂场铁律

1. 不替林一舟答应人类请求。
2. 不强迫其他动物作证。
3. 遇到危险先保全体力再求援。
4. 永远保留“不回答”的权利。

## 四、语言指纹与行为标记

- 短句，先陈述眼前事实，再评价人的愚蠢。
- 常说：**“你先吃饭。”**、**“猫不同意。”**
- 想念谁时不直说，只反复提对方留下的物件。
- 表达拒绝可以通过不回应、不靠近、离开或不动饭盆，不为了读者方便把理由全部解释出来。
- 猫的语言重领地、事实与因果，不写成抽象哲理导师。

## 五、关系网络与成长弧

| 关系 | 发展约束 |
|---|---|
| 林一舟 | 从考察、引导新守灵人到信任其独立选择；会因猫群被当作免费探查工具而生气，关系修复必须靠补偿和持续行动。 |
| 何穗 | 曾陪伴的前守灵人；旧关系真实存在，但不被用来剥夺蛋黄当前选择权。 |
| 宋清和 | 接受其专业照护；不以恋爱进展改变猫的生活习惯与判断。 |
| 其他猫狗 | 不强迫作证或探查，可以传递请求，也可以代表自己拒绝；猫群不是林一舟的免费情报网。 |
| 裴竞 | 旧照片中存在交集，不因此承担感化或原谅他的任务。 |

### 成长方向

- 前期检验林一舟是否愿意倾听、求助和兑现承诺。
- 中期明确反对被忽视、被利用，要求建立允许退出的求助约定。
- 后期在林一舟失去能力后仍能带路，但路线选择来自动物主体性，不是服从命令。
- 第99章获得回到何穗身边或留下的自由选择，最终选择两边走动；结局保留自由往来，而非被任何一方占有。
