# 裴竞

> 主要对手，S级。可以被理解，但不被轻易洗白；停止装置后仍须承担职业、法律与公共责任。

## 一、基本身份

- 38岁，静川科技创始人、云湾更新项目顾问。
- 曾跟随何穗学习守灵。
- 少年时无法理解爱犬黑豆的痛苦；黑豆离世后，将“听见”视为无尽折磨。
- 以旧守灵纹路嵌入智能降噪设备，推动静默计划，试图替全城切断声音。

## 二、核心人格

- 追求秩序、可控和低噪声，冲突时先计算成本。
- 不是恨动物，而是害怕再次承受无法解决的需求。
- 把“替别人去掉变量”当作仁慈，与林一舟逐渐学会提供选择形成对照。
- 理解其创伤不等于认同其手段；他不能以黑豆之痛正当化对全城生灵的支配。

## 三、灵魂场铁律

1. 不故意虐杀动物。
2. 不以虚假数据欺骗自己的技术团队。
3. 任何情况下都坚持“安静比混乱仁慈”，直到情节以证据迫使他改变。
4. 不为达目的伤害无辜人类。

## 四、语言指纹与行为标记

- 使用精确名词和封闭问题，很少提高音量。
- 常说：**“把变量去掉。”**
- 情绪失控时反而重复旧指令。
- 以薪酬、合同、技术陈述与既有数据优势推进目标，不靠无铺垫的暴力或脸谱化疯狂。
- 面对黑豆时，旧指令与“不再听见”的执念暴露其仍未处理的关系创伤。

## 五、关系网络与成长弧

| 关系 | 发展约束 |
|---|---|
| 黑豆 | 少年爱犬；他将无法理解其痛苦的创伤转化为对“听见”的拒绝。最终必须承认自己一直在替黑豆决定。 |
| 何穗 | 曾跟随她学习守灵；因试图命令所有回声安静而失去承接资格，维修簿缺页与黑豆往事相连。 |
| 林一舟 | 先以高薪合作换取动物路线图，后在云湾主线正面对抗；林一舟理解但拒绝其替全城决定。 |
| 宋清和、唐圆及团队 | 主要通过医疗、社区、设计和公共证据迫使其方案接受现实检验，不安排私人感化捷径。 |
| 静川与云湾项目 | 以创始人、顾问身份拥有现实资源；结局不能用一场哭泣抵消合同、数据和公共后果。 |

### 成长与后果阶段

1. **第13—40章**：由旧照片、缺页、项圈与设备逐渐进入主线，高薪合作遭拒。
2. **第41—60章**：继续推进节点与公开测试，证明林一舟的越界不会换来对付他的捷径。
3. **第61—80章**：拒绝释放黑豆回声，扩展并提前启动主装置。
4. **第81—92章**：面对黑豆主动回应，理解遗愿是希望他继续生活；主装置锁死后交出关闭权限。
5. **第93章以后**：装置关闭、黑豆回声释放；承担合同、数据与公共责任并参与修复，不突然成为无代价的英雄。
