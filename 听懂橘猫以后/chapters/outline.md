# 总大纲 · 五卷一百章

正文约30万字，每章2800—3200字。以下为不可更改的核心事件、人物抉择与结局；具体场景可增强因果，但不得改动主线。

## 第一卷：猫开口的那个雨夜（1—20）

**卷目标**：能力觉醒、人兽相遇、规则初探；以梧桐里小型静默事件证明城市玄幻真实存在。卷尾从“我是不是病了”转为主动调查。

| 章 | 标题 | 核心事件与章尾牵引 |
|---|---|---|
| 1 | 雨夜猫说话 | 加班、抢功、父亲康复费压在身上；雨夜听见蛋黄抱怨，蛋黄指出楼下有狗在哭。 |
| 2 | 不是幻听 | 用距离、录音、提问测试能力；录音无效。发现流浪狗豆包，送南窗动物医院，初见宋清和。 |
| 3 | 狗记得的路 | 宋清和处理脱水；林一舟依狗的气味与地标记忆画路线图，开始找主人。 |
| 4 | 诊疗不是翻译 | 蛋黄说喝水不舒服，他误以为挑食；宋清和查出早期泌尿问题，划清翻译与诊疗边界。 |
| 5 | 第一次回应 | 豆包与住院归来的主人重逢，留下第一枚回声标记；光纹钻进旧巷。宋清和注意到他在看“那里”。 |
| 6 | 加班与罐头 | 设计被郑启铭拿去汇报，母亲催回乡；附近狗群同时避开一条街。 |
| 7 | 半夜的猫群会议 | 主动参加猫群会议，得知一只猫在“没有声音”的小巷失踪；线索指向新装降噪设备。 |
| 8 | 不存在的门牌 | 用旧改造图与猫的路线找到被遮住的门牌，发现图纸上没有的通道。 |
| 9 | 兽医不看玄学 | 宋清和检查被困动物伤迹；她不信玄学但承认证据，先救再说。 |
| 10 | 墙里的叫声 | 救出夹层中的猫，灵隙短暂开启，听见不同年代同类叫声重叠。 |
| 11 | 走失的名字 | 猫只回应旧名字，循此找到搬走的老住户完成安置；设备再次启动。 |
| 12 | 一碗温水的代价 | 连续倾听导致听不清人声，只能写字；第一次确认能力有代价。 |
| 13 | 旧照片里的蛋黄 | 何穗旧物中有蛋黄、何穗与年轻裴竞的合影；蛋黄拒绝解释。 |
| 14 | 养老院的提问 | 何穗不直接教学，要求他先学会问清楚再救，交给缺页维修簿。 |
| 15 | 被退稿的设计 | 动物友好动线方案被公司退回；图角出现与旧巷设备相同的静川标志。 |
| 16 | 会绕路的石头 | 老狗石头绕开某街，确认设备切断动物熟悉路径，而非单纯降噪。 |
| 17 | 一个人的排查 | 夜间独自测绘被困，感官过载；蛋黄拒绝替他求救，要他明确开口。 |
| 18 | 猫狗的合唱 | 他放下逞强请求带路，猫狗接力引导宋清和与唐圆找到他与失踪动物。 |
| 19 | 小巷重新有声音 | 依维修簿关闭试验节点，以现实改造打通逃生通道；危机靠合作解决。 |
| 20 | 听见城市 | 决定查清设备来源；城市微光连成网络；蛋黄承认他像点守灵人的样子。 |

## 第二卷：每一条小巷都有回声（21—40）

**卷目标**：扩展物种与守灵历史，建立询问、拒绝、误判、修正的伦理；爱情以信任为主；事业线与静川正式交汇。

| 章 | 标题 | 核心事件与章尾牵引 |
|---|---|---|
| 21 | 普通星期一 | 能力不改善工作；办公室鹦鹉反复说“别关窗”。 |
| 22 | 鹦鹉不说欢迎 | 调查发现鹦鹉模仿装修指令，真问题是雨燕巢将被封。 |
| 23 | 翅膀的方言 | 首次听鸟类方位语言，必须结合飞行观察，不能用猫狗逻辑套用。 |
| 24 | 给雨燕留一条缝 | 用可施工的小改造保住雨燕通道，靠专业与倾听赢得客户认可。 |
| 25 | 蛋黄的旧主人 | 何穗说明蛋黄观察八个月、雨夜救助触发承接；能力有原因，不是天命。 |
| 26 | 守灵人的规矩 | 何穗以案例教“不读心、不役使、不替代现实行动”；维修簿中黑豆名字被撕去。 |
| 27 | 仓鼠的第三十一次跑轮 | 异常跑轮被当可爱视频；他查出环境拥挤与昼夜颠倒，推动改善而非夺走宠物。 |
| 28 | 不听命令的狗 | 南窗接收“攻击性”狗；宋清和先排查疼痛，林一舟听见它对围栏声的恐惧。 |
| 29 | 误解的代价 | 凭片面描述误判主人虐待并公开质问，随后发现信息缺口，必须道歉并消除影响。 |
| 30 | 不能替它们回答 | 重新征得狗的回应，让主人参与行为调整；石头带他找到被抹名的黑色项圈铭牌。 |
| 31 | 城市背面的地图 | 叠合病例、动物路线与设备位置，发现节点沿云湾更新带分布。 |
| 32 | 何穗与裴竞 | 何穗承认裴竞是学徒，黑豆死后他试图命令所有回声安静，失去承接资格。 |
| 33 | 温柔不是顺从 | 王秀兰来城，安排回乡；她与蛋黄意外相处，却在工作上与儿子僵持。 |
| 34 | 一顿没吃完的饭 | 家庭争吵摆开金钱、康复与“为你好”；他明确拒绝回乡，同时承诺共同承担费用。 |
| 35 | 南窗的手术夜 | 宋清和面对无法保证结果的手术；他不能用法力帮忙，只提供后勤与陪伴。 |
| 36 | 她不问的秘密 | 宋清和早察觉异常，但愿意等他主动坦白，不逼问。 |
| 37 | 云湾更新招标 | 尺度设计参与云湾项目；裴竞认出图纸与灵隙有关，提出高薪合作。 |
| 38 | 一份体面的价码 | 他因家庭开支认真权衡；发现对方要动物路线图后明确回绝。 |
| 39 | 被拿走的方案 | 郑启铭用他的设计外观却删去动物保护措施；内部会议拿出证据反对。 |
| 40 | 停职之夜 | 被停职，收入骤降；灵隙地图同时亮起更多静默节点，个人与城市危机并线。 |

## 第三卷：不能替它们做决定（41—60）

**卷目标**：让男主犯下真正的伦理错误并付出代价；向宋清和坦白；完成职业转向，成为真正的守灵人。

| 章 | 标题 | 核心事件与章尾牵引 |
|---|---|---|
| 41 | 没有工作的一个早晨 | 停职后面对账单与失序生活，接小项目；兔子持续躲进浴室。 |
| 42 | 兔子的避暑权 | 查出高温与噪声不适，改善环境；认识到很多“神奇”只是认真观察。 |
| 43 | 南窗的临时设计顾问 | 宋清和邀他改造候诊动线，按猫狗感官需求分区，不靠逐只聊天。 |
| 44 | 猫狗分开的候诊室 | 改造降低应激，客户主动合作；职业价值开始脱离原公司评价。 |
| 45 | 广场上的刺猬 | 景观灯改变刺猬路径；协调关灯时段，城市共生扩展到非宠物议题。 |
| 46 | 被拒绝的好意 | 社区反对投喂流浪猫；他必须面对卫生、噪声与居民真实困扰。 |
| 47 | 不是每只猫都想回家 | 以绝育、定点护理、栖息地调整替代强行收养；接受部分猫留在原地。 |
| 48 | 蛋黄生气了 | 蛋黄指出他让猫群免费打探消息却不兑现安全与食物承诺；搭档裂缝。 |
| 49 | 动物也有拒绝权 | 他补偿并建立求助约定，允许中途退出；蛋黄重新回应，但信任需行动维护。 |
| 50 | 第一次越界 | 为尽快取得证据，强行让狗类回声重复痛苦记忆，违背规则。 |
| 51 | 静音 | 同时失去动物语言与发声能力；静川节点继续推进，越界没有换来捷径。 |
| 52 | 她听见他的沉默 | 以文字坦白全部秘密；宋清和接受事实，拒绝纵容他伤害自己或动物。 |
| 53 | 诊疗单之外 | 两人划清医学、能力与私人关系边界；宋清和也承认自己过度承担。 |
| 54 | 重新学会敲门 | 不以道歉索取原谅，持续照顾受影响的狗并等待回应；恢复的第一步是允许不原谅。 |
| 55 | 旧商场的宠物展 | 静川赞助的宠物展用动物表演造噱头；过载与设备测试同时发生，团队疏散。 |
| 56 | 不能带走的乌龟 | 旧喷泉旁的乌龟回声不能迁走，必须保留水温与旧址连接。 |
| 57 | 一座会呼吸的商场 | 提出兼顾动物、商户、居民的替代设计，获商户联署；郑启铭重估他的价值。 |
| 58 | 辞职不是胜利演说 | 平静辞职，没有暴富打脸；以小型共生项目维持生计，承担不确定性。 |
| 59 | 守灵人的第二课 | 受影响动物自愿回应，何穗指出守灵人不是生灵的主人。 |
| 60 | 城市回应了他 | 动物开放安全路径，形成有限共听；裴竞启动云湾第一轮全区测试。 |

**卷目标**：事业、爱情、家庭在共同危机中成熟；危机前确认关系，不用生死冒险代替告白；卷尾剥夺能力。

|---|---|---|

| 68 | 家里那只猫 | 蛋黄陪父亲训练，母亲看见儿子照顾生命的能力。 |
| 69 | 回家不是认输 | 达成边界：父母不再以回乡为唯一答案，他不再隐瞒困难。 |

| 75 | 他只想让世界安静 | 与裴竞正面对话，理解创伤但拒绝其替全城决定；裴竞不释放回声。 |

| 77 | 没有翻译的救援 | 能力断续，靠观察、食物与动线救援；成长脱离金手指。 |

| 80 | 全城静音 | 裴竞提前启动主装置，江洲陷入异常寂静；他彻底听不见动物，光纹熄灭。 |

## 第五卷：当万灵重新开口（81—100）

**卷目标**：以无金手指行动验证主题；全城普通人与动物的互相回应完成高潮；事业、爱情、家庭具体落地。

| 章 | 标题 | 核心事件与章尾牵引 |
|---|---|---|
| 81 | 无声的第一天 | 用文字、视觉信号与记录继续工作；宋清和与他重新分配任务。 |
| 82 | 不用能力也能听见 | 凭姿态、环境与经验识别狗的需求，倾听内化为专业与尊重。 |
| 83 | 宋清和的选择 | 她组织跨院分诊与社区医疗点，成为救援网络核心之一。 |

| 85 | 何穗的最后一把钥匙 | 交出维修簿索引：钥匙不是法器，是人与动物互相回应的关系网。 |
| 86 | 找回第一个声音 | 石头在旧主人回应后发出第一声吠叫，一个节点松动。 |
| 87 | 一百个微小的回应 | 居民、商户、兽医、志愿者以喂食、开门、引路、认领旧承诺唤醒节点；概述推进。 |
| 88 | 裴竞的黑色项圈 | 黑豆回声寻找裴竞；林一舟不截留、不利用，只把选择权交还。 |

| 94 | 天亮以后 | 处理伤病、安置与善后，吃一顿迟来的早饭；胜利落回具体动作。 |
