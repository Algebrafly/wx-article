# 《听懂橘猫以后》五卷100章总大纲

> 固定总纲，故事开始状态。写作时只允许为增强因果微调场景，不擅自改变核心抉择与结局。每章先完成当前阶段的小结果，再落实对应末拍；末拍必须进入正文最后300—600字，不得只停留在大纲中。

## 第一卷：猫开口的那个雨夜（第1—20章）

**卷目标**：完成能力觉醒、人兽相遇和规则初探；用梧桐里小型静默事件证明城市玄幻真实存在。卷尾由“我是不是病了”转为主动调查城市。

| 章节 | 标题 | 核心事件与章尾牵引 |
|---|---|---|
| 1 | 雨夜猫说话 | 林一舟加班回家，在工作与父亲康复费用的双重压力下听见蛋黄抱怨；橘猫指出楼下有只狗在哭。 |
| 2 | 不是幻听 | 他用距离、录音和简单问题测试能力，发现录音无效；流浪狗豆包坚持主人没有抛弃自己，林一舟带它去南窗动物医院。 |
| 3 | 狗记得的路 | 宋清和处理豆包脱水，林一舟依据狗对气味、门洞和地标的零碎记忆画路线图，开始主动寻找主人。 |
| 4 | 诊疗不是翻译 | 蛋黄说喝水不舒服，林一舟误以为是口味问题；宋清和检查出早期泌尿问题，明确翻译不能替代诊疗。 |
| 5 | 第一次回应 | 豆包与出差归来的主人重逢，自愿道谢后留下光纹；林一舟看见光纹钻进梧桐里的旧巷。 |
| 6 | 加班与罐头 | 他的设计被郑启铭拿去汇报，家中母亲再次劝回乡；蛋黄用猫的方式催他吃饭，附近狗群却同时避开一条街。 |
| 7 | 半夜的猫群会议 | 林一舟主动参加“猫群会议”，得知一只猫在没有叫声的小巷失踪；猫提供的线索指向新装的降噪设备。 |
| 8 | 不存在的门牌 | 他结合旧改造图和猫的路线找到被遮住的门牌，发现一条图纸里不存在、动物却能走进去的通道。 |
| 9 | 兽医不看玄学 | 他带宋清和检查被困动物留下的伤迹；她不信玄学但承认证据，决定先救人救猫再讨论原因。 |
| 10 | 墙里的叫声 | 两人救出困在旧墙夹层的猫，灵隙短暂开启；林一舟听见许多不同年代的同类叫声重叠。 |
| 11 | 走失的名字 | 获救猫只回应旧名字，众人循此找到搬走的老住户，完成现实安置；旧巷的设备却再次启动。 |
| 12 | 一碗温水的代价 | 连续倾听让他突然听不清宋清和的人声，只能写字交流；他第一次意识到能力并非免费。 |
| 13 | 旧照片里的蛋黄 | 他在何穗留下的旧物中发现蛋黄、何穗与年轻裴竞的合影，蛋黄拒绝解释，只要求先吃饭。 |
| 14 | 养老院的提问 | 何穗不直接上课，只让他先学会“问清楚再救”，并交给他一本缺页的旧维修簿。 |
| 15 | 被退稿的设计 | 林一舟提出动物友好商场动线，被公司以增加成本为由退回；方案角落出现与旧巷设备相同的静川标志。 |
| 16 | 会绕路的石头 | 老狗石头每次经过某街都绕路，林一舟跟随它确认设备能切断动物熟悉的路径，而非简单降低噪声。 |
| 17 | 一个人的排查 | 他夜里独自测绘灵隙，被设备引发的感官过载困住；蛋黄拒绝替他求救，要求他自己发出明确请求。 |
| 18 | 猫狗的合唱 | 林一舟放下逞强，请动物带路；梧桐里的猫狗自愿接力，引导宋清和与唐圆找到他和失踪动物。 |
| 19 | 小巷重新有声音 | 众人依维修簿关闭试验节点，并用现实改造打通逃生通道；第一卷小型危机以合作而非法力爆发解决。 |
| 20 | 听见城市 | 林一舟决定查清设备来源，城市中的微光在他眼前连成网络；蛋黄承认：“你终于像点守灵人的样子了。” |

## 第二卷：每一条小巷都有回声（第21—40章）

**卷目标**：扩展动物种类与守灵历史，建立“询问、拒绝、误判、修正”的伦理；爱情以信任为主。事业线与静川的云湾项目正式交汇。

| 章节 | 标题 | 核心事件与章尾牵引 |
|---|---|---|
| 21 | 普通星期一 | 林一舟回到令人窒息的日常，发现能力不会自动改善工作；一只办公室鹦鹉反复说“别关窗”。 |
| 22 | 鹦鹉不说欢迎 | 他调查后确认鹦鹉是在模仿装修指令，真正问题是窗外雨燕巢即将被封；鹦鹉只能提供部分事实。 |
| 23 | 翅膀的方言 | 林一舟首次听见鸟类零碎的方向语言，必须结合飞行观察理解需求，避免把猫狗规则套给鸟类。 |
| 24 | 给雨燕留一条缝 | 他用可落实施工的小型改造保住雨燕通道，第一次靠专业与倾听共同赢得客户认可。 |
| 25 | 蛋黄的旧主人 | 何穗说明蛋黄观察林一舟八个月，雨夜救助触发承接；能力有选择原因，却不是天命特权。 |
| 26 | 守灵人的规矩 | 何穗通过实际案例教他“不读心、不役使、不替代现实行动”；维修簿中黑豆的名字被刻意撕去。 |
| 27 | 仓鼠的第三十一次跑轮 | 一只仓鼠的异常跑轮被当成可爱视频，林一舟发现环境拥挤和昼夜颠倒，推动主人改善而非夺走宠物。 |
| 28 | 不听命令的狗 | 南窗接收一只看似攻击性的狗，宋清和先排查疼痛，林一舟听见它对某种围栏声的恐惧。 |
| 29 | 误解的代价 | 林一舟凭片面描述误判主人虐待并公开质问，随后发现信息缺口；他必须道歉并修正传播影响。 |
| 30 | 不能替它们回答 | 他重新征得狗的回应，让主人参与行为调整；石头带他找到一块被抹除名字的黑色项圈铭牌。 |
| 31 | 城市背面的地图 | 林一舟把病例、动物路线与设备位置叠成灵隙地图，发现所有节点都沿云湾更新带分布。 |
| 32 | 何穗与裴竞 | 何穗承认裴竞曾是学徒，黑豆离世后他试图命令所有回声安静，因此失去承接资格。 |
| 33 | 温柔不是顺从 | 王秀兰突然来城，试图安排儿子回乡；她与蛋黄意外相处融洽，却在工作问题上与林一舟僵持。 |
| 34 | 一顿没吃完的饭 | 家庭争吵把金钱、康复和“为你好”摆上桌；林一舟首次明确拒绝回乡，却也承诺共同承担现实费用。 |
| 35 | 南窗的手术夜 | 宋清和面对无法保证结果的手术，林一舟无法用法力帮忙，只安静提供后勤和陪伴；她的防线稍松。 |
| 36 | 她不问的秘密 | 宋清和说明自己早察觉他获取信息的方式异常，但愿意等他主动坦白；两人的信任不依赖逼问。 |
| 37 | 云湾更新招标 | 尺度设计正式参与云湾项目，裴竞认出林一舟的图纸与灵隙有关，提出高薪合作。 |
| 38 | 一份体面的价码 | 林一舟因家庭开支认真权衡，而非立刻伟光正拒绝；发现对方要的是动物路线图后，他明确回绝。 |
| 39 | 被拿走的方案 | 郑启铭采用他的设计外观却删去动物保护措施，林一舟在内部会议上拿出完整证据反对。 |
| 40 | 停职之夜 | 他被停职，收入压力骤增；灵隙地图同时亮起更多静默节点，个人困境与城市危机正式并线。 |

## 第三卷：不能替它们做决定（第41—60章）

**卷目标**：让男主犯一次真正的伦理错误并付出代价；向宋清和坦白。完成从压抑职场到独立共生设计的职业转向，并成为真正意义上的守灵人。

| 章节 | 标题 | 核心事件与章尾牵引 |
|---|---|---|
| 41 | 没有工作的一个早晨 | 林一舟面对停职后的账单和失序生活，接小项目维持收入；一只兔子持续躲进浴室，带来新求助。 |
| 42 | 兔子的避暑权 | 他发现兔子并非胆小而是高温与噪声不适，改善环境后问题缓解，也认识到很多“神奇”其实是认真观察。 |
| 43 | 南窗的临时设计顾问 | 宋清和邀请他改造候诊动线，他以猫狗不同感官需求设计分区，不靠与每只动物聊天完成方案。 |
| 44 | 猫狗分开的候诊室 | 新候诊室降低应激，专业客户主动找他合作；他的职业价值开始脱离原公司的评价体系。 |
| 45 | 广场上的刺猬 | 夜间景观灯改变刺猬活动路径，林一舟、唐圆与物业协调关灯时段，城市共生不再只是宠物议题。 |
| 46 | 被拒绝的好意 | 社区居民反对投喂流浪猫，林一舟起初只想护猫，随后不得不面对卫生、噪声与居民真实困扰。 |
| 47 | 不是每只猫都想回家 | 团队以绝育、定点护理和栖息地调整替代强行收养；林一舟接受部分猫选择留在熟悉领地。 |
| 48 | 蛋黄生气了 | 蛋黄指出他总让猫群免费打探消息，却没有兑现安全与食物承诺；主角与搭档之间出现真实裂缝。 |
| 49 | 动物也有拒绝权 | 林一舟补偿并建立求助约定，允许动物中途退出；蛋黄重新回应，但信任仍需后续行动维护。 |
| 50 | 第一次越界 | 为尽快取得静川证据，他强行让一段狗类回声重复痛苦记忆，明确违背已学规则。 |
| 51 | 静音 | 他同时失去动物语言与发声能力，灵隙关闭；裴竞的节点却继续推进，越界没有换来捷径。 |
| 52 | 她听见他的沉默 | 宋清和通过文字得知全部秘密与他的自我消耗；她接受异常事实，但拒绝纵容他再次伤害自己或动物。 |
| 53 | 诊疗单之外 | 两人约定医学、魔法和私人关系的边界；宋清和坦白自己也有过度承担的问题，关系向平等靠近。 |
| 54 | 重新学会敲门 | 林一舟不以道歉索取原谅，持续照顾受影响的狗并等待回应；恢复能力的第一步是允许对方不原谅。 |
| 55 | 旧商场的宠物展 | 静川赞助的宠物友好展以动物表演制造噱头，动物过载与设备测试同时发生，团队介入疏散。 |
| 56 | 不能带走的乌龟 | 众人发现旧喷泉旁的乌龟回声不能随意迁走，必须保留水温与旧址连接；所谓救助再次让位于真实需求。 |
| 57 | 一座会呼吸的商场 | 林一舟提出兼顾动物、商户和居民的替代设计，获得商户联署；郑启铭不得不重新评估他的专业价值。 |
| 58 | 辞职不是胜利演说 | 他平静辞职，没有突然暴富或全面打脸；以小型城市共生设计项目维持生计，并承担选择的不确定性。 |
| 59 | 守灵人的第二课 | 受影响动物终于自愿回应，何穗指出守灵人不是生灵的主人；林一舟接受责任而非身份优越感。 |
| 60 | 城市回应了他 | 动物主动开放安全路径，形成有限的“共听”；与此同时，裴竞启动云湾第一轮全区静默测试。 |

## 第四卷：一座城市的失眠（第61—80章）

**卷目标**：让事业、爱情、家庭三条线在共同危机中成熟；男女主在危机前确认关系而非用生死冒险代替告白。卷尾剥夺能力，迫使最终卷回到人的成长。

| 章节 | 标题 | 核心事件与章尾牵引 |
|---|---|---|
| 61 | 城市失眠夜 | 静默测试令动物焦躁、灵隙紊乱，南窗夜诊骤增；林一舟和宋清和先建立可持续轮班，而非硬撑。 |
| 62 | 鸽群不再回家 | 鸽群失去旧航线并撞上玻璃，林一舟发现设备干扰了灵隙中的方向记忆。 |
| 63 | 给天空留路 | 他用玻璃识别、灯光与临时引导争取一条安全通道，前卷雨燕改造经验得到回响。 |
| 64 | 宋清和的诊室 | 宋清和因病例增加濒临过载，主动分诊并请求同行支援，实践自己也需要边界的成长。 |
| 65 | 不是救世主的两个人 | 两人争论谁该休息，最后制定共同值守规则；亲密来自可执行照顾，而不是牺牲比赛。 |
| 66 | 天台上的半句话 | 林一舟准备坦白感情时被小危机打断，宋清和没有装不懂，约定忙完后把话说完。 |
| 67 | 父亲的康复清单 | 父母来城复诊，看见儿子停职后的真实处境；林国平以自己的康复清单鼓励他一步一步来。 |
| 68 | 家里那只猫 | 蛋黄陪林国平完成日常训练，王秀兰看见儿子照顾生命的能力，也开始正视他的疲惫。 |
| 69 | 回家不是认输 | 一家人达成边界：父母不再以回乡为唯一答案，林一舟也不再隐瞒经济困难；亲情不依赖完全理解玄幻。 |
| 70 | 一份共同署名的方案 | 林一舟、宋清和与唐圆提交云湾共生方案，分别负责空间、医疗与社区证据，事业与爱情保持平等。 |
| 71 | 被否决的听证会 | 方案因静川的既有合同和数据优势被否决；团队发现裴竞准备把测试扩至主城区。 |
| 72 | 雨声里的告白 | 在没有救援任务的雨夜，两人完成那次未说完的对话，确认恋爱关系；蛋黄只关心晚饭是否迟到。 |
| 73 | 恋爱以后仍要上班 | 用便利店晚餐、候诊室小憩和一起画图呈现新关系；甜蜜不暂停现实责任，也不制造低级误会。 |
| 74 | 黑豆的项圈 | 黑色项圈与维修簿缺页拼合，证明黑豆最后的回声仍被裴竞保存在主装置里。 |
| 75 | 他只想让世界安静 | 林一舟与裴竞正面对话，理解其创伤但拒绝其替全城做决定；裴竞不愿释放黑豆回声。 |
| 76 | 静默区扩张 | 多个街区动物停止发声，普通人也开始忽视宠物异常；团队按地图组织现实救援。 |
| 77 | 没有翻译的救援 | 林一舟能力断续，只能靠宋清和训练过的观察、食物与动线完成救援，成长开始脱离金手指。 |
| 78 | 连人声也消失 | 他为引导狗群离开崩塌灵隙而过载，短暂失声；宋清和制止他继续独自承担，团队接棒。 |
| 79 | 让蛋黄带路 | 林一舟把选择权交给蛋黄和动物群，自己负责清除现实障碍；他们找到主装置启动时间。 |
| 80 | 全城静音 | 裴竞提前启动主装置，江洲陷入异常寂静；林一舟彻底听不见动物，维修簿上的光纹全部熄灭。 |

## 第五卷：当万灵重新开口（第81—100章）

**卷目标**：用无金手指行动验证主题，以全城普通人与动物的互相回应完成高潮；事业、爱情、家庭均有具体而不夸张的结果，最后回到温暖日常。

| 章节 | 标题 | 核心事件与章尾牵引 |
|---|---|---|
| 81 | 无声的第一天 | 林一舟用文字、视觉信号和既有记录继续工作；没有突然恢复能力，宋清和与他重新分配任务。 |
| 82 | 不用能力也能听见 | 他凭姿态、环境与既往经验识别一只狗的需求，证明倾听已内化为能力之外的尊重与专业。 |
| 83 | 宋清和的选择 | 她组织跨院分诊和社区医疗点，拒绝只转移动物而丢下行动不便的主人，成为救援网络的实际主导者之一。 |
| 84 | 一座城的备用方案 | 团队利用灵隙地图、救助记录和普通市民报点重建节点，不再依赖林一舟一个人听见。 |
| 85 | 何穗的最后一把钥匙 | 何穗交出维修簿缺失的索引：所谓钥匙不是法器，而是曾被记录的人与动物互相回应的关系网。 |
| 86 | 找回第一个声音 | 石头在旧主人回应它的等待后发出第一声吠叫，一个静默节点松动，证明修复必须由双方完成。 |
| 87 | 一百个微小的回应 | 居民、商户、兽医与志愿者以喂食、开门、引路、认领旧承诺等行动唤醒节点；概述推进，不写流水账。 |
