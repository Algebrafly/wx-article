# 人物状态

## 第50章结束（第三卷中段·越界）

**林一舟**：七月二十日晚越界后，声带水肿、发不出声音（禁声，待次日喉镜）；同时失去对动物语言的理解——蛋黄的叫声变回普通猫叫，听不懂任何意思；左耳蝉声转为空白。仍停职，靠零散收入维持；本批为TNR试点垫资约一千元。第一次真正违反“三不”（不役使），也第一次切身意识到自己与裴竞的相似。尚未向宋清和坦白能力。

**宋清和**：猜到他在逼回声重复痛苦记忆，制止并把他拖出声场；检查出他声带水肿，要求禁声与喉镜；仍不知能力全部真相，但已接近临界点。大顺良性脾脏血肿恢复中。

**蛋黄**：在越界现场多次叫他走、咬他裤脚，未被听从；事后仍跟在他身边，但他已听不懂。信任未完全修复，关系处于“它还在、但他听不懂”的状态。

**唐圆**：拍到016铭牌与测试区设备；在越界现场用身体挡住他与设备；对他的状态感到害怕，提醒他“叫了你十遍你不回”。

**孙桂芳**：喂后巷猫五年，配合TNR试点；后巷猫群有了定点护理与绝育安排。

**陈主任（居委会）**：同意一个月TNR试点，负责消杀与协调；观望结果。

**老黄**：流浪老狗，回声困于云湾测试区设备声场，活体下落不明；其痛苦回声被林一舟越界利用。

**裴竞**：未正面出场；云湾第一轮全区测试七月十五日启动，四台新设备在梧桐里东口到云湾之间联调。

**何穗**：未出场；其“不要重复裴竞的路”的警告在第50章被林一舟切身理解。

**郑启铭**：未联系。

**林国平、王秀兰**：不知儿子停职与失声。

## 更新规则

每章结束后更新：身体状态、情绪基线、已知信息、关系变化、工作/收入、随身物品。未知信息必须标注“不知道”，防止角色说出不该知道的事。
