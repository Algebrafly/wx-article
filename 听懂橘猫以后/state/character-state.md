# 人物状态

## 第40章结束（第二卷完）

**林一舟**：六月二十九日被停职一个月，停职期间只发基本工资2280元，收入缺口约6000元；门禁卡已交，工位保留。左耳高频下降三十分贝、耳鸣持续，需复查。已知道裴竞是何穗的旧学徒、黑豆之死的经过；拒绝静川年薪28万的顾问合同；掌握静川设备编号013—015与泵房黑点的资料。与宋清和处于“她已知异常、他承诺会坦白”的阶段；与唐圆、陈院长有零散收入来源；蛋黄尚未正式见证他承接守灵人。

**宋清和**：知道林一舟听力受损，明确察觉他有秘密，但同意“等他说”；设下三条边界。大顺术后进入危险期，病理未出；候诊区改造已走小额采购3500元。对裴竞保持专业礼貌，未参与静川合作。

**蛋黄**：健康稳定；闻过黑豆铭牌后躲进沙发底，拒绝解释；尚未正式答应见证。对林一舟停职后的经济压力无概念，只在意他是否按时回家、是否吃饭。

**裴竞**：静川创始人，何穗十四年前的学徒；黑豆之死的当事人。已向林一舟开出年薪28万、分成千分之五的顾问合同，被拒；不怒，判断“他会回来”。云湾测试继续推进。

**何穗**：安宁康养院317房；已讲明蛋黄来历、守灵三不、黑豆事件；警告林一舟“不能替一座城市决定安静”。身体尚可，但不是随叫随到的百科。

**郑启铭**：用林一舟的设计外观投标，删去动物保护措施；在标前会被当众用证据反驳后，推动停职。仍是设计总监，掌握项目话语权。

**唐圆**：持续拍摄云湾设备，拍到013—015与泵房无编号机柜；介绍宠物店搬笼子的零工；与林一舟保持协作，但提醒他“别把动物当情报”。

**小陆**：尺度设计同事，按郑启铭参数改出A-11；保留12345工单截图，对林一舟有愧疚，不敢公开站队。

**王秀兰**：六月十八至二十日来城，发现儿子听力报告与真实经济状况；接受“不回乡”但要求两个月回一次、过年回家；带走新的康复计划与账目安排，仍怀疑他有事瞒着。

**林国平**：术后康复继续，能走六圈；县医院康复科周医生接手训练；不知儿子停职。

**石头**：十岁老狗；带林一舟找到黑豆铭牌后反应异常，贴着墙不肯再往前；未被强迫。

**大顺**：十一岁黑黄狗，脾脏肿块破裂，六月二十日夜手术；术后四十八小时危险期，病理五至七天后出结果。

**阿凯与芝麻**：仓鼠主人阿凯已换大笼、遮光、换垫料；芝麻状况改善。

**将军**：被投诉“攻击性”的田园犬，主人马师傅；已排查牙结石、耳道与施工声恐惧，进入脱敏与行为调整。

## 更新规则

每章结束后更新：身体状态、情绪基线、已知信息、关系变化、工作/收入、随身物品。未知信息必须标注“不知道”，防止角色说出不该知道的事。
